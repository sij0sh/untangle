# SQL
- Identify the owning capability and declared write path for every table.
- Preserve primary/foreign keys, uniqueness, NULL, time zone, money precision and transaction invariants.
- Trace transaction isolation, conflicts, retries and external effects before any query/schema simplification.
- Consider external query consumers, migrations, views, procedures and triggers—not just application imports.
- Do not call destructive or lock-affecting changes behavior-preserving without proof and rollback planning.
